# Stage 1 Extra Audit Resources

This folder contains additional figures and grids for the first methodology section of the report.

These outputs support the justification of the input image audit before moving to preprocessing filters and channel construction.

## Added analysis

- Resolution distribution
- Intensity distribution
- Contrast distribution
- Dynamic range distribution
- Gray-level entropy distribution
- Aggregate gray-level histogram
- Aggregate gray-level CDF
- Histograms by intensity group
- Histograms by contrast group
- Histograms by entropy group
- Representative grids by visual condition
- Representative grids by noise cluster
- Panels combining radiograph, histogram and CDF

## Purpose

The purpose is to show that preprocessing and channel design are data-driven. The audit identifies photometric, tonal, structural and noise-related variability before segmentation training.
